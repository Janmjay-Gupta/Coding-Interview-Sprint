The 5 Core Derivation Triggers

Transform $O(N^2)$ brute forces into $O(N)$ with this mental framework

1 Linear search inside a nested loop → HashMap / HashSet

If your inner loop exists solely to ask: "Have I seen the complement (target - x) or this value before?", replace the $O(N)$ inner search with an $O(1)$ amortized Hash Table lookup.

2 Comparing all past elements against today → Running Aggregate

If you are looking back at every previous day to maximize difference, you do not need every day stored. You only need the single historic minimum seen so far.

3 Sorted Array + pair / triplet condition → Two Pointers

Sorted elements give directional guarantee: sum = nums[L] + nums[R]. If too small, advance L++. If too large, retreat R--. Discard half the search space without nested loops.

4 Contiguous Substring / Subarray constraint → Sliding Window

Instead of generating $O(N^2)$ candidate slices, keep an expandable window [L, R]. Expand R to add state; when a rule breaks, advance L to restore validity.

5 Sorted or Rotated Array in $O(\log N)$ → Binary Search

Compare middle element nums[mid]. In rotated arrays, at least one half is always cleanly sorted. Determine if the target falls within that sorted half, then halve the search space.
